# Performance monitor with [psutil](https://psutil.readthedocs.io/stable/) Python library

System Monitoring Dashboard UI for tracking key system performance metrics:

* RAM: Tracks memory usage percentage, total size, and available memory.

* CPU: Monitors processor load percentage, core count, and clock frequency.

* SWAP: Displays swap space usage percentage, total, used, and free space.

* Disk: Shows storage drive usage percentage, total capacity, used space, and free space.

* Network: Lists network traffic counters for bytes and packets sent/received.

* Info: Displays general system status, including boot time and hardware temperature (if available).
